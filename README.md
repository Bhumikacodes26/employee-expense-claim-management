# Employee Expense Claim Management

This repository contains the complete React + Vite POC source as a ZIP archive.

## Get the source code
1. Download `employee-expense-claim-management.zip` from this repository.
2. Extract the ZIP.
3. Open the extracted `employee-expense-claim-management` folder in VS Code.
4. Run:
   ```bash
   npm install
   npm run dev
   ```

The extracted project folder contains `package.json`, `index.html`, `src/App.jsx`, `src/main.jsx`, `src/styles.css`, and a detailed project README.

## Stack
React, Vite, JavaScript, Material UI, React Router, Recharts and browser localStorage.

## POC note
This is a front-end demonstration. Role selection is simulated, and the receipt field stores a filename rather than uploading a file. See the README inside the ZIP for workflows, business rules and limitations.
